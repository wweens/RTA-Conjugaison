Les quatre temps simples à connaître par cœur

Les quatre temps simples essentiels de l’indicatif.

Présent
Action actuelle ou vérité générale ; terminaisons fréquentes : -e, -es, -e / -s, -s, -t.
Ex. je chante ; nous finissons
Imparfait
Action qui dure, se répète ou décrit ; radical de « nous » + -ais, -ais, -ait, -ions, -iez, -aient.
Ex. je chantais ; ils finissaient
Passé simple
Action achevée, souvent au premier plan du récit.
Ex. je chantai ; il finit ; ils vinrent
Futur simple
Action à venir ; infinitif + -ai, -as, -a, -ons, -ez, -ont.
Ex. je chanterai ; nous finirons

Le secret des temps composés

Auxiliaire être ou avoir + participe passé.

Passé composé
Auxiliaire au présent + participe passé.
Ex. tu as compris
Plus-que-parfait
Auxiliaire à l’imparfait + participe passé.
Ex. tu avais compris
Passé antérieur
Auxiliaire au passé simple + participe passé.
Ex. tu eus compris ; il fut parti
Futur antérieur
Auxiliaire au futur + participe passé.
Ex. tu auras compris

Les six modes

Le mode montre comment l’action est envisagée.

Indicatif
Présente l’action comme réelle.
Ex. je chante ; j’ai chanté
Impératif
Exprime un ordre ou un conseil ; sans sujet exprimé.
Ex. Chante ! Aie chanté !
Subjonctif
Exprime souhait, doute, nécessité ou possibilité.
Ex. que je chante ; que j’aie chanté
Conditionnel
Exprime une action possible sous condition ou un fait hypothétique.
Ex. je chanterais ; j’aurais chanté
Infinitif
Forme non personnelle, souvent comme nom du verbe.
Ex. chanter ; avoir chanté
Participe
Forme non personnelle servant notamment aux temps composés.
Ex. chantant ; chanté
💡 La méthode RTA
Observe, cherche un indice, applique l’astuce, puis vérifie. Une bonne méthode aujourd’hui, c’est un point de plus demain !
